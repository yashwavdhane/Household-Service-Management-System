# Guidance to Run

Follow these steps to run the Household Service Management System (HSMS) manually on your device.


### Step 1: Run the Backend
Open a terminal in your project's root folder and run the following commands:
```powershell
cd backend
npm run dev
```
*(The server will start on `http://localhost:5000`)*

### Step 2: Run the Frontend
Open a **second, separate terminal** in your project's root folder and run the following commands:
```powershell
cd frontend
npm run dev
```
*(The React app will start on `http://localhost:5173`)*

---

### 🌐 Access Your App
Once both the frontend and backend terminals show that they are running, simply open your web browser and navigate to:
**http://localhost:5173**
